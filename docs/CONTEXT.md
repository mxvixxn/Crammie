# Crammie — 프로젝트 메모

> 최종 갱신: 2026-09-27

## 1. 한 문단 요약

**Crammie(크래미)** 는 시험 직전 벼락치기(cram)를 돕는 **macOS 앱**입니다.
교재 PDF를 넣으면 시험 범위의 핵심 개념을 뽑아 암기를 확인하고, AI가 간단한 시험 문제를 만들어 줍니다.
예: 백신 통합과학2 교재 PDF → 시험 범위 페이지만 골라 → 개념 카드 + 문제 풀이.

- 사용자: **본인 혼자** (배포·공유 계획 없음)
- 사용 기기: **맥에서만**
- UI 문구는 한국어, 다정한 존댓말 톤 (Vocabie와 동일)

## 2. 결정해 둔 것

| 항목 | 결정 | 이유 |
|---|---|---|
| 플랫폼 | **macOS 앱** (웹·iOS 아님) | 맥에서만 사용. 서버 불필요, 도메인 비용 없음, 7일 만료 문제 없음 |
| 언어 / UI | **Swift, SwiftUI** | Vocabie로 이미 익숙함 |
| 타깃 OS | **macOS 27** (현재 사용 중인 버전) | |
| 영속성 | SwiftData | |
| PDF | **PDFKit** (미리보기, 페이지 선택, 텍스트 추출) | 애플 순정 |
| AI | **Claude API**, `URLSession`으로 직접 호출 | 공식 Swift SDK가 없음 |
| API 키 보관 | 맥 **키체인** | 혼자 쓰는 로컬 앱이라 서버를 둘 필요 없음 |
| 외부 의존성 | 없음 | Vocabie와 같은 원칙 |
| 서명 | Personal Team (무료) | 프로비저닝 프로파일이 필요한 기능(iCloud 등)은 피한다. 필요해지면 7일 만료 문제가 생김 |

온기기 AI(Foundation Models)는 컨텍스트가 약 4,096토큰이라 교재 분량에 부족해 쓰지 않는다.

## 3. ★ 핵심 기능 메모 — PDF는 통째로, 범위는 앱에서

> **교재 PDF 전체를 그대로 넣고, 설정 화면에서 시험 범위 페이지를 지정한다.**
> 사용자가 PDF를 미리 잘라서 넣을 필요가 없어야 한다.

- PDF 파일을 통째로 불러온다 (드래그 앤 드롭 / 파일 열기)
- **설정 화면에서 페이지 범위를 지정**한다
  - 예: `45-78`, 여러 구간도 허용 `12-20, 45-78`
  - 썸네일로 보면서 고를 수 있으면 좋음 (PDFKit `PDFThumbnailView`)
- AI에게는 **선택한 페이지만** 보낸다 → 비용·정확도 모두 유리
  - PDFKit으로 선택 페이지만 새 PDF로 추출해 전송
- 범위는 교재별로 저장해 두고 나중에 바꿀 수 있게 한다

⚠️ **책 쪽수 ≠ PDF 페이지 번호**인 경우가 많다 (표지·목차 때문에 어긋남). 범위를 "책 쪽수"로 입력받을지, "PDF 페이지"로 받을지, 오프셋 보정을 넣을지 구현할 때 결정할 것.

## 4. 학습 흐름 (초안)

```
PDF 불러오기 → 설정에서 시험 범위 페이지 지정
   → AI가 핵심 개념 카드 생성 (개념 · 정의 · 헷갈리는 포인트)
   → ① 개념 훑기 → ② 객관식/OX → ③ 빈칸·서술형
   → 틀린 것만 다시 풀기 → 오답 노트
```

- Vocabie의 **암기 → 리콜 → 스펠** 흐름을 "개념" 버전으로 옮긴 구조
- 틀려도 벌하지 않고 틀린 것만 뒤에서 반복한다 (Vocabie 원칙 승계)
- AI가 만든 문제에는 **근거 페이지**를 같이 표시한다. AI가 틀릴 수 있으므로 직접 확인할 수 있게

## 5. 비용

- 호스팅·도메인: 없음 (로컬 앱)
- 개발자 프로그램: 불필요 (Personal Team)
- **Claude API 사용료만 발생.** 시험 범위만 보내서 줄인다

## 6. 주의

- 시판 교재 PDF는 **본인 학습용으로만** 사용한다. 교재 내용이나 생성한 문제를 공유·공개하지 않는다
- 이 저장소의 코드는 리눅스 컨테이너에서 작성될 수 있어 **빌드 검증은 맥에서** 해야 한다
